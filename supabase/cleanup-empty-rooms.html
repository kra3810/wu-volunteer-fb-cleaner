ตรวจสอบห้องตกค้าง

เปรียบเทียบรายการห้องใน Supabase กับ rooms_meta ของ Firebase ซึ่งเป็นแหล่งข้อมูลจริงที่หน้า Hub ใช้แสดงห้อง

เกณฑ์ที่แก้ไข: ห้องที่ไม่มีรหัสอยู่ใน Firebase rooms_meta คือห้องตกค้างที่ Migration รอบก่อนสร้างเพิ่มจาก key ใน rooms โดยผิดพลาด ห้องที่มี Metadata อยู่ใน Firebase จะถูกเก็บไว้ แม้ยังไม่มีข้อมูลภายในก็ตาม
ห้องใน Supabase—
มีอยู่ใน Firebase Hub—
ห้องตกค้าง—
กดตรวจสอบเพื่อเริ่มต้น

ลบเฉพาะห้องที่ไม่มีรหัสใน Firebase rooms_meta เท่านั้น และลบข้อมูล room_data ที่ผูกกับห้องนั้นผ่าน ON DELETE CASCADE ไม่แตะ Firebase
