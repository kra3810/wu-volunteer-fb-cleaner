ย้ายข้อมูล Firebase → Supabase

คัดลอกเฉพาะห้องที่มี Metadata ใน rooms_meta ซึ่งเป็นแหล่งข้อมูลที่หน้า Hub ใช้แสดงรายการห้อง

หมายเหตุ: จะไม่สร้างห้องจาก key ที่พบเฉพาะใน rooms เพราะอาจเป็นข้อมูลตกค้าง/ห้องกำพร้า การย้ายจะไม่ลบข้อมูล Firebase และไม่ลบห้องอื่นที่มีอยู่ใน Supabase

ใช้ Firebase REST API อ่านข้อมูลเดิม และ Supabase Publishable key สำหรับเขียนข้อมูล
